【关键指标】训练时间对比
========================================================================================================================

根据训练日志: 每次迭代实际耗时约 3.6 秒
Profiler 配置: wait=10, warmup=1, active=3, repeat=1

关键发现:
• CPU 累计时间(24.2s) >> 实际迭代时间(3.6s)
  → 说明大量 CPU 操作与 GPU 并行执行
  
• 并行效率 = 1 - (实际时间 / CPU时间)
             = 1 - (3.6 / 8.07)
             ≈ 55.4%
  → CPU-GPU 流水线已有不错的重叠

• GPU 实际计算时间: 2.14s/迭代
  → GPU 利用率 = 59.5% (基于3.6s墙上时间)
  → 仍有优化空间，理想情况可接近 2-2.5s/迭代
